# Feasibility boundary diagnostics

This analysis reuses the frozen context-sweep measurements at
`experiments/roofline_validation/context_sweep_rtx4050_bb0fdb9/`. Raw measurements
remain unchanged. The analysis was generated by commit
`3a88f4119ae934958cd2af0c5bb47742094d9ae2` and is stored in
`context_sweep_rtx4050/prediction_errors.json` with two figures.

The 144 held-out action/prompt/context rows cover six CNN/DM prompts at four
synthetic context lengths. The predictor used the calibration vanilla baseline;
the diagnostic classifier additionally substitutes measured prompt-matched vanilla
TPS. That second baseline is only available after the run and cannot be used by a
runtime router.

| Profitable threshold | Calibrated baseline TP / FP / FN / TN | Measured vanilla baseline TP / FP / FN / TN |
|---|---|---|
| > 1.00 | 0 / 0 / 13 / 131 | 1 / 5 / 12 / 126 |
| > 1.03 | 0 / 0 / 9 / 135 | 1 / 1 / 8 / 134 |
| > 1.05 | 0 / 0 / 4 / 140 | 1 / 0 / 3 / 140 |

The calibration vanilla baseline differed from held-out prompt-level vanilla TPS by
1.53 tokens/s MAE and 3.77% MAPE. Replacing it with measured vanilla TPS recovers a
few profitable cases but still has low recall (7.7%, 11.1%, and 25.0% across the
three thresholds). Therefore baseline calibration error contributes, but does not
explain most false negatives. All 13 false negatives at the 1.00 calibrated
threshold are listed in the JSON; they are all K=2 cases. The largest measured gains
occur on `cnndm_020`, including 1.101x for CKA-60/K2, while the frozen model predicts
0.835x for that case.

This is a sensitivity analysis over single measurements, not evidence that gains
above 1.03 or 1.05 are repeatable. The held-out set has six prompt clusters and the
context expansion is synthetic token repetition. It diagnoses the boundary model;
it does not validate natural long-context behavior or provide runtime oracle labels.
